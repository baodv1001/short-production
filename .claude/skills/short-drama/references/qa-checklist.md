# QA checklist (use before each export)

## Story
- [ ] Hook in the first 3-5 s
- [ ] 2-3 plot twists
- [ ] Cliffhanger in the last shot
- [ ] Vietnamese dialogue is natural, kinship terms are correct

## Visual
- [ ] Same face in all shots for each character
- [ ] Same clothes and accessories (no drift)
- [ ] Same style, lens, and light in all shots
- [ ] No wrong hands, no broken motion, no strange text in the picture
- [ ] Vietnamese details are correct (signs, vehicles, clothes)

## Audio
- [ ] One fixed voice for each character
- [ ] Lip sync tested on one clip before the full episode
- [ ] Voice and effects are aligned with each clip
- [ ] Music volume is lower than voice
- [ ] Same loudness in all clips

## Finish
- [ ] Color temperature and contrast match in all clips
- [ ] Subtitles: one font, one color, one position, no spelling errors in Vietnamese tones
- [ ] Export 9:16, 1080p
- [ ] AI label added when the platform asks for it
- [ ] No real person's face or voice used
